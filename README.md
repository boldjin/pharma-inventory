# 의약품 재고관리 시스템

브라우저에서 동작하는 의약품 재고관리 웹앱입니다. 데이터는 사용자 브라우저의 localStorage에만 저장되며 서버로 전송되지 않습니다.

## 주요 기능

- **대시보드**: 월별 매입/매출 트렌드, 품목별 재고 현황, 재고 알림
- **현재재고**: 품목별 현재 재고와 안전재고 비교, 상태 표시
- **매입현황**: 품목 + 기간 필터, 월별 매입 트렌드, 거래처별 비중
- **매출현황**: 품목 + 병원 + 월 필터, 마진 자동 계산, 월별 매출 트렌드
- **입출고기록**: 매입/매출/폐기/반품/조정 CRUD
- **품목관리**: 품목 마스터 데이터 CRUD

## 사용 방법

[GitHub Pages 링크](https://boldjin.github.io/pharma-inventory/)에 접속하면 바로 사용 가능합니다.

데이터는 브라우저에 저장되므로:
- 같은 브라우저로 재접속 시 입력한 데이터가 유지됩니다
- 다른 PC/브라우저에서 접속 시 빈 상태(데모 데이터)로 시작합니다
- 브라우저 데이터 삭제 시 모든 입력 내역이 사라집니다

## 데이터 안내

리포지토리에 포함된 SEED 데이터는 **모두 가상의 데모 데이터**입니다 (샘플품목 A~E, A~E병원).

## 기술 스택

- Vanilla HTML/CSS/JS (빌드 도구 없음)
- Chart.js (CDN)
- 브라우저 localStorage
